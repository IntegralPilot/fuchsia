# Python

Python is a scripting language from [python.org](https://python.org/).

## Python interpreter

Fuchsia vendors its own Python 3 interpreter (`//scripts/fuchsia-vendored-python`,
currently Python 3.11 or later). See
[Python versions](python_style.md#python-versions) in the style guide and
[RFC-0129](/docs/contribute/governance/rfcs/0129_python_in_fuchsia.md).
