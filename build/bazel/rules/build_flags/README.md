# `build_flags()` Bazel macros and tests

The `build_flags()` rules are available in `@fuchsia_rules_common//build_flags:*`.

See [`//build/bazel_sdk/fuchsia_rules_common/build_flags/README.md`](
  /build/bazel_sdk/fuchsia_rules_common/build_flags/README.md) for more information.

This directory only contains a `tests/` directory with the in-tree tests of the
`build_flags()` macros.
